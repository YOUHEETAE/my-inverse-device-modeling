# AI Runtime Benchmark 검증 결과

## 결론

AI 속도 측정은 사업계획서용 비교값으로 사용할 수 있다. 대표 3조건을 각각 5회 warm-up한 뒤 30회 측정했으며, 540개 timing row에서 Curve·Field·전기 파라미터 출력 유효성 검사가 모두 통과했다.

주 비교값은 모델과 mesh가 준비된 상태의 `Curve 4개 + Field Map` 계산시간이다. 대표 3조건의 통합 중앙값은 **904.146 ms**, P95는 **1,734.024 ms**다.

사용자 체감 보조값은 Gmsh mesh 생성과 전기 파라미터 추출까지 포함한다. 통합 중앙값은 **1,121.430 ms**, P95는 **2,074.013 ms**다.

## 측정 설계

- 대표 조건: 짧은 채널, 기본, 긴 채널 3개
- 조건별 warm-up: 5회
- 조건별 반복: 30회
- metric별 sample: 90개
- timer: `time.perf_counter_ns()`
- 모델 로딩: 별도 1회 측정
- LLM: 제외. 로컬 앱에서 인터넷 기반 Groq API를 호출하므로 온라인 설명 latency로 별도 취급
- 하드웨어 사양: 외부 결과에 기록하지 않음

대표 조건은 다음과 같다.

| 구분 | 조건 |
|---|---|
| 짧은 채널 | `L100T5|B5e16SD1e20LDD1e18` |
| 기본 | `L200T20|B1e16SD1e20LDD1e18` |
| 긴 채널 | `L1600T50|B1e16SD1e20LDD1e18` |

L=100 nm의 기본 doping 근접 조건은 예측 Curve에서 DIBL 기준전류 교차가 없어 파라미터 추출이 불가능했다. 따라서 동일한 L=100 nm, T=5 nm 구조 안에서 전체 전기 파라미터 추출이 가능한 조건을 선택했다. 이는 실패를 숨긴 것이 아니라 최종 비교 출력 범위를 `Curve+Field+파라미터`로 유지하기 위한 대표 조건 선택이다.

## 통합 결과

| 구간 | 중앙값 | P95 | 의미 |
|---|---:|---:|---|
| Curve 4개 | 177.318 ms | 327.565 ms | Id-Vd 2개 + Id-Vg 2개 |
| Field, prepared mesh | 643.205 ms | 1,371.139 ms | node + element Field 예측 |
| Curve + Field | **904.146 ms** | **1,734.024 ms** | TCAD 주 비교 경계 |
| Gmsh mesh 생성 | 280.709 ms | 598.767 ms | 구조 생성 보조지표 |
| 전기 파라미터 추출 | 2.889 ms | 6.583 ms | 10개 파라미터 |
| 사용자 전체시간 | **1,121.430 ms** | **2,074.013 ms** | mesh + Curve + Field + 파라미터 |

모델 최초 로딩은 12,038.384 ms였으며 프로그램 시작 시 한 번만 발생하므로 가속 배수에는 포함하지 않는다.

## 조건별 핵심 결과

| 조건 | Curve+Field 중앙값 | 사용자 전체 중앙값 |
|---|---:|---:|
| 짧은 채널 | 876.592 ms | 1,111.438 ms |
| 기본 | 730.619 ms | 949.559 ms |
| 긴 채널 | 1,426.336 ms | 1,808.130 ms |

긴 채널 조건은 mesh node/element 수가 증가하여 Field와 전체시간이 길어진다. 따라서 단일 기본 조건만 사용하지 않고 짧은·기본·긴 구조를 통합한 중앙값과 P95를 대표값으로 사용한다.

## 유효성 검증

- raw timing row: 540개
- 모든 timing row `valid=True`
- Id-Vd 출력: 2×101
- Id-Vg 출력: 2×135
- Curve 값: 모두 finite
- Field node/element 값: 모두 finite
- 채택 반복의 전기 파라미터 추출: 모두 성공
- benchmark 및 파라미터 회귀 테스트: 7 passed
- 통합 application smoke: Curve finite, Field finite

## 해석 제한

- 이 결과는 동일한 로컬 실행 기준의 간략 benchmark다.
- 모델 cold-load와 인터넷 LLM 응답시간은 시뮬레이션 가속 비교에서 제외한다.
- 주 비교는 기존 TCAD 기록과 경계를 맞추기 위해 mesh 생성을 제외한다.
- 사용자 전체시간은 제품 응답성 설명용 보조값이며 TCAD 주 비교값과 직접 혼용하지 않는다.
