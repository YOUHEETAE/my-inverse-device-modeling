# SemiScopeAI

반도체 소자 교육용 학습 도구입니다. 구조와 도핑 조건을 바꾸면 전기적 특성이
어떻게 달라지는지, 예측 모델과 TCAD 시뮬레이션 결과로 보여줍니다.

이 폴더는 **설치도 인터넷도 없이 한 대의 PC에서 도는 빌드**입니다. 웹 서비스
(https://semiscopeai.com)와 같은 화면, 같은 계산 코드를 씁니다.

---

## 실행 방법

1. **`SemiScopeAI.exe`를 실행합니다.**
2. 잠시 뒤 **기본 브라우저가 자동으로 열립니다.**
   열리지 않으면 검은 창에 표시된 주소(`http://127.0.0.1:8765/`)를 직접
   입력하십시오.
3. 종료할 때는 검은 창을 닫으면 됩니다.

### 처음 실행할 때 두 가지

**"Windows가 PC를 보호했습니다"라는 파란 창이 뜹니다.**
*추가 정보* → *실행*을 누르십시오. 코드 서명 인증서를 구입하지 않은 실행
파일에 Windows가 붙이는 안내이며, 프로그램의 문제가 아닙니다.

**첫 실행은 30초쯤 걸립니다.** 글꼴 정보를 준비하느라 그렇습니다. 두 번째부터는
10초 안에 열립니다.

---

## 5분 둘러보기

바로 보시기 좋은 순서입니다.

**1. I-V Curve** — 왼쪽 파라미터에서 `L`(채널 길이)을 `500`에서 `200`으로 바꾸고
**Add**를 누르십시오. 두 조건의 전류 곡선이 겹쳐 그려지고, 아래 표에 문턱전압과
on/off 전류비가 함께 나옵니다. 채널을 줄이면 전류는 늘지만 off 상태가 나빠지는
trade-off가 그대로 보입니다.

**2. Field Map** — 같은 조건에서 소자 내부의 전위와 전기장 분포를 봅니다. 오른쪽
위 목록에서 `Energy band (1D)`를 고르면 에너지 밴드 다이어그램으로 바뀝니다.

**3. Theory** — 반도체 물리 6개 장입니다. PN 접합과 MOS Capacitor는 값을 바꿔가며
직접 돌려볼 수 있습니다.

**4. Case Study** — 이 도구의 핵심입니다. 케이스를 하나 고르면 네 단계로 진행합니다.

> **예측** — 조건을 바꾸면 어떻게 될지 먼저 답한다
> **실험** — 실제로 계산해서 결과를 본다
> **관찰** — 그래프에서 무엇이 보이는지 답한다
> **채점** — 예측이 맞았는지 문항마다 표시되고, 모범 답안이 나온다

먼저 예측하게 하고 결과와 맞춰보게 하는 구성입니다. 결과만 보여주면 "그렇구나"
하고 넘어가지만, 먼저 답을 적어두면 틀린 지점이 분명해집니다.

## 이 빌드에 없는 것

| 기능 | 로컬 실행판 |
|---|---|
| I-V Curve 예측 · 조건 비교 | 그대로 동작 |
| Field Map · 에너지 밴드 | 그대로 동작 |
| Theory 6개 장과 시뮬레이터 | 그대로 동작 |
| Case Study 8종 · 4단계 · 채점 · 모범답안 | 그대로 동작 |
| **AI 설명 · AI 자유질문** | **없음** |
| 로그인 · 계정별 학습 기록 | 없음 |

**AI 기능만 빠져 있습니다.** 외부 AI 서비스를 호출하는 기능이라 인증 키가
필요한데, 실행 파일에 키를 넣으면 압축을 푸는 것만으로 꺼낼 수 있어 넣지
않았습니다. 해당 자리에는 안내 문구가 대신 표시됩니다.

**AI 설명과 자유질문의 실제 동작은 https://semiscopeai.com 에서 보실 수 있습니다.**

**Case Study 채점은 AI 없이도 그대로 됩니다.** 채점은 케이스마다 정해둔 정답과
대조하는 계산이고, 모범 답안은 케이스 정의와 실제 시뮬레이션 결과를 조합해
만들기 때문입니다. AI는 피드백 문장을 다듬는 역할입니다.

**로그인이 없어** 모든 기능이 바로 열려 있습니다. 학습 기록은 실행 파일 옆
`SemiScopeAI-data/` 폴더에 저장되며, 이 폴더를 지우면 처음 상태로 돌아갑니다.

## 참고

- **인터넷에 아무것도 보내지 않습니다.** 모든 계산이 이 PC 안에서 끝납니다.
- 실행 중 열리는 주소 `127.0.0.1`은 이 PC 자신을 가리킵니다. 외부에서는 접속할
  수 없습니다.
- Windows 10 이상 64비트에서 동작합니다.
